# Play Store listing: DieCut

Paste these into Play Console. Limits are Google's: title 30, short description 80,
full description 4,000. Nothing below uses "best", "#1", emoji, or calls to action in the
title, all of which Play rejects.

## Title (27 / 30)

```
DieCut: Sticker Maker & GIF
```

Why this shape: brand first, then the exact high-volume phrase "Sticker Maker", then "GIF".
The title carries the most search weight on Play. "WhatsApp" is kept out of the title
because Meta's brand guidelines forbid using it as part of a product name; it appears in the
descriptions as a compatibility statement instead.

## Where the competitive keywords go

| Keyword | Where | Why |
|---|---|---|
| sticker maker | Title | Highest-volume phrase; the market leader uses it in its title |
| GIF | Title | "GIF maker" is a medium-competition term (difficulty about 52/100) |
| WhatsApp, stickers | Short + full description | Compatibility wording, kept out of the title for trademark reasons |
| background remover, cutout | Full description | A hard keyword (difficulty about 70/100); better as a long-tail than a title slot |

Play indexes the title, short description and full description, and has no hidden keyword
field, so the full description is where long-tail phrases belong. Re-check rankings after any
title change before making a second one.
